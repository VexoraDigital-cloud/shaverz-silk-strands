PUBLISH WITH GITHUB PAGES (FREE)
1. Create/open a PUBLIC GitHub repository.
2. Upload these three files into the repository root (not inside another folder).
3. Commit the files.
4. Open Settings > Pages.
5. Under Build and deployment choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish the site.

IMPORTANT
- GitHub Pages is static hosting. The appointment form opens the visitor's email app with a pre-filled message. It does not store or automatically send form submissions. The visitor must press Send.
- The WhatsApp button uses the supplied phone number.
- Gallery and style images are remotely hosted by Unsplash and require an internet connection.
- Gallery photos are visual inspiration, not confirmed photos of the business's own work. Replace them with approved salon photos before treating this as the salon's official portfolio.
- Confirm the business owner approves the design, content, images and publication before making it public as their official website.
- No prices, opening hours, physical address, reviews or awards have been invented.
